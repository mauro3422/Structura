# v1.2.24 - Refactor de laboratorio SQL y capas de widgets

## Cambios

- Extraje la logica del laboratorio SQL en capas mas claras: analisis, lectura, persistencia, vistas y acciones.
- Separe el dispatcher de comandos de UI en familias mas pequenas para tablas, columnas, filas y feedback.
- Aisle la vista de reglas del laboratorio y la vista de observaciones para que `renderers.ts` quede solo como composicion.
- Movi los defaults del laboratorio a un modulo propio y deje `markup.ts` como proveedor de fragmentos HTML.
- Reorganice el CSS de tablas y widgets en archivos mas honestos segun su responsabilidad.
- Endureci contratos de tipo en el laboratorio y en el core para reducir estados invalidos.
- Ajuste la base del sistema de secciones para seguir analizando el endurecimiento del resto del sistema sin perder compatibilidad.

## Validacion

- `npm run typecheck`
- `npm test`
- `npm run build`
